# AI 描述词 - 提示动效（原创复刻版）

源视频本集未配描述词版式，以下按正片机制原创撰写。

- 红点展开：`点击红点后，提示内容从红点位置展开出现，不要凭空淡入。`
- 提示队列：`多条提示依次排队进场，每条带 8px 上移加淡入，间隔 80ms，不要同时涌入。`
- 撤销条：`删除后底部出现撤销条，带线性倒计时进度（默认 5 秒），走完才消失；对应行的红点沿原路缩回散掉并高亮该行一下。`
- 角标：`角标数字变化时先撑开容器宽度（约 100ms），数字再滚动翻位，相邻图标位置不被挤动。`
- 横幅：`横幅从顶部挤下，页面内容同步下移让位，不要做覆盖式浮层。`
- 新建面板：`点击加号后新面板以加号圆心为 transform-origin 长出，列表同步让位，新建内容落入列表。`
- 未读分割线：`未读分割线保持位置，列表滚过它后才淡出，淡出完成后再回收高度，列表不突然跳动。`
- 红点连锁：`处理一条未读后，行角标、分组角标、顶部总数按约 65ms 间隔依次递减，不要三层同时跳变。`

# Web 高级交互 10 种（《Skill实战》第19集，全文）

来源：西瓜同学《UI高级审美设计｜Skill实战》第19集（页面显示 10月6日，03:29），合集播放链接 modal_id=7693492904148405550。页面年份未显示。

总原则：页面上每个能点的元素都要有停留反馈 — 光标、按钮、导航和图片都应跟着操作回应，而不是只做静态页面。

1. 滚动钉住主图：页面滚动时主图固定不动，旁边的文字依次切换；主图随滚动进度推近并突出重点区域。
2. 光标成为页面一部分：隐藏系统光标，改用跟随鼠标的小圆点；移到大图上时圆点放大为橙色圆并在中央出现"查看"类文字（画面标注放大尺寸 88px），移到按钮上缩回小点，离开图片后平滑缩回原尺寸。
3. 磁吸按钮：鼠标靠近时按钮被光标吸过去，松开后弹回原位。
4. 图标按钮展开标签：鼠标停在圆形图标按钮上，展开对应的文字标签，移开后恢复圆形。
5. 导航底色跟随：导航后方放一块绝对定位的圆角底色；悬停时读取目标项的位置与宽度，以弹性缓动跟随过去并同步改变宽度；移出导航后回到当前页面对应项。
6. 功能块悬停翻色：以右上角箭头为圆心，用圆形扩散的方式让主色覆盖整个功能块，文字颜色同步反转，箭头方向随之旋转。
7. 分档拖动条：拖动圆钮时数字一格一格变化，走过的区域同步变橙色，松手后自动吸附到最近档位。
8. 数据图表跟随鼠标：鼠标在柱状图上横向移动时竖线跟随，当前柱子亮起，顶部数字实时变化。
9. 悬停预览图片：鼠标滑到文字列表某一行，对应的图片浮出来；换一行，图片跟着换。
10. 圆形扩散换肤：点击切换按钮后，新主题从一点向外圆形扩散、逐步覆盖旧主题，完成配色切换（官方章节要点只列到第 9 个，此为画面标题第 10 个；实现技术未明示）。

互引：圆形扩散与 qson_ui_transitions 的圆形扩散是同一机制 — 转场场景正主在 transitions，Web 换肤场景在本条；分档拖动条与 qson_ui_components 的刻度调节同族，区别是本条为鼠标拖动圆钮的分档滑杆；功能块翻色的扩散圆心在块内箭头处，与弹窗类的定点起源（qson_ui_cards 的 POP）互引。

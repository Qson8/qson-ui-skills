# Web 交互 AI 描述词（原创转述）

- 自定义光标：`隐藏系统光标，用一个小圆点跟随鼠标；移到大图上时圆点放大到 88px 变成橙色圆，中央显示"查看"二字；移到按钮上缩回小点；所有变化平滑过渡，不要跳变。`
- 导航底色跟随：`导航项后方放一块绝对定位的圆角底色块；鼠标悬停到某项时，底色块读取该项的位置和宽度，用弹性缓动滑过去并同步改变宽度；鼠标移出导航后，底色块回到当前页面项。`
- 悬停预览：`文字列表行悬停时，对应图片在列表旁浮出显示；切换到另一行时图片平滑换成那一行的图；图片跟随鼠标的纵向位置，不要遮挡文字。`
- 圆形扩散换肤：`点击主题切换按钮后，新主题从点击点开始以圆形扩散的方式覆盖全页完成换肤，不要瞬间闪换；扩散期间旧主题保持不动。`

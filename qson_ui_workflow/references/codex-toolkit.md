# Codex 生态工具条（浩兰德《Codex新手必装的6个神级插件》）

来源：小红书作者浩兰德，视频《Codex新手必装的6个神级插件🔥》，2026-10-08 发布，时长 3 分 20 秒，直达 https://www.rednote.com/discovery/item/6ac767990000000018012cba 。提取口径：以视频画面字幕与演示录屏文字为准，口播未逐字转录；安装细节中 Caveman 的获取方式与 Playwright 的安装渠道来自作者评论区确认，已逐条注明。本条与《Skill实战》方法条互补：那边是做 UI 的工作流，这边是执行工具（Codex）的能力补齐清单。

## 与本库的关系

- 这 6 个里有四个本质是 Skill 或 MCP：给执行工具补能力的标准方式已经从「改软件」变成「装技能包」，与本库「把方法沉淀成可安装 Skill」的立场一致。
- 其中 Playwright MCP 已在本库七步工作流第 7 步（自动测试与修复）出现，本条补上它作为独立调研工具的用法；Superpowers 的流程补强七步中的第 2 步「想清需求」。

## 流程模式：先问清，再动手（Superpowers）

- 治的问题：执行工具接到大活一上来就写代码，方向错了再返工。
- 流程：先把需求问清 → 列出方案与步骤 → 形成设计文档 → 人确认 → 才动手写代码；问清阶段明确「本轮不写代码」。
- 与七步工作流的对应：第 2 步「想清需求」的可执行版本——想清不是自己想，是让工具先反问、成文、等确认。与本库分工恒定原则（想清楚做什么的角色与执行角色分开）同向。

## 六件工具清单（按视频顺序）

1. **Computer Use**（官方插件）：让 Codex 操控整台电脑——看屏幕、点按钮、开软件，不再只在聊天框里干活。安装：插件面板搜索开启，首次使用点「允许」。
2. **Caveman**（Skill，GitHub：JuliusBrussee/caveman，据作者评论区确认）：压缩上下文废话省 Token。原则是代码、命令、文件路径、完整报错不压缩，安全警告与确认提示保留完整句子，只砍回答周围的铺垫；视频对比为同一问题 69 → 19 tokens。
3. **Playwright**（MCP，微软官方 microsoft/playwright-mcp）：只管浏览器——开网页、点按钮、填表单，用于上网调研。与 Computer Use 的分工：浏览器专用 vs 整个桌面。安装据作者评论区为插件面板搜索。
4. **Superpowers**（官方插件）：见上「流程模式」。安装为插件面板搜索开启（据作者评论区，除 Caveman 外其余大部分为官方渠道）。
5. **办公三件套**（官方自带 Skill）：Documents 写 Word、Spreadsheets 做表格、Presentations 做 PPT，插件面板开启即用，免下载；目的是不再在 WPS 与飞书之间来回切换。
6. **hollandcut**（Skill，作者自制开源，GitHub：holoraai/hollandcut）：视频剪辑，一键成片，lite / pro / max 三档；原视频即用它剪辑。装法值得记：直接让 Codex 自己去 GitHub 搜项目名装好，并明确要求先装到 /tmp 临时目录测试、不动现有 skills 目录——新 Skill 先隔离试装再入正式目录，与本库收纳纪律同向。

## 验证法：重启后自报

- 装完统一验证：安全退出 Codex → 重新打开 → 问它「装了哪些插件」，能逐个报出名称与加载形态（Skill / MCP / 已启用）即为安装与加载正常。
- 口径提醒（作者原注）：这确认的是安装与加载状态，未逐项执行功能测试；「装好」与「用好」分开记账，与本库状态梯（描述 / 有 demo / 生产用过）同一纪律。

## 呈现观察（不另立条目）

- 视频用「盖章」动效逐项确认安装状态（开启 ✓、先问清楚 · 再动手、6 项全部已装 ✓），最后给一屏逐项汇总确认。属于完成反馈的呈现手法，与 `qson_ui_feedback` 的完成确认同族，此处仅记录出处，不重复收录。

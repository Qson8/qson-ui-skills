# AI 描述词 - 高级审美布局（原创复刻版）

源视频第3集未配描述词版式，第12集描述词正文未完整读出。以下为按画面结构原创撰写，可直接粘给 Agent，再补你的内容字段。

## 通用

```
页面不要等宽等高平铺。先定一个主角：主图或主数字面积至少是次要块的3倍。
其余元素围绕主角排，主次用面积和黑白拉开，不要靠加边框和阴影区分层级。
```

## 配方

- 宽体标题大图列表：`顶部两行宽体大写无衬线标题，下面圆角搜索栏右配黑色圆形筛选按钮，再下一排分类标签；列表每项一整张16:10大图，标题参数和箭头排在图下一行。`
- 大图头块叠信息：`顶部大图头块，倒计时和主按钮叠在图上；图下白底天气条、日期块，5天温度用一条平滑曲线连起，再接行程列表。`
- 黑白两档：`浅灰底，黑色大块当主角配白字，分类选中态翻转为黑底白字，底部一条黑色横幅，全页只用黑白灰。`
- 大色块网格：`浅灰底，一个亮黄色大色块放核心数字当主角，配圆环完成度；标题超粗中英混排，下方四列小格放次要数据。`
- 海报转盘：`海报式方块大字标题，中部半圆转盘选一项（每格30度），超大数字，黑色主按钮，底栏用撞色。`
- 叠放堆栈：`细长宽体标题加分类行，大图卡片前后叠成堆栈露边，配页码如 2/5 示意层数。`

## 原则速用

`卡片错位：两列高度故意不一左右错开` / `层叠：标签压卡、卡压图，用遮挡做纵深` / `留白：一屏只讲一件事，元素删到10个以内，间距放大`

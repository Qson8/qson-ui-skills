# Dashboard 实现要点（Web 后台向）

适用：Thymeleaf/Spring 后台（VoteBoard、Pollux、AheadOA 类）、一般 Web 管理端。

## 主题变量

- 把背景、卡片、文字、强调收成四个 CSS 变量（或主题 token），浅/深主题只换变量组；深色主题必须同时给出文字变量的高对比值，不许只改背景（第9集明示）。
- 点缀色纪律落到变量层：强调变量只允许被当前态、主按钮、关键曲线三类选择器引用，评审时可全局搜索检查，防颜色蔓延。

## 导航

- 双层轨与折叠展开用纯 CSS/少量 JS 宽度过渡即可实现；文字淡入延迟与栏体宽度动画分开计时（展开先行、文字晚约 80ms 为视频标注值）。
- 底部固定区用 flex 列布局：导航区 flex:1 独立滚动，用户区固定在底，不用绝对定位硬顶。
- 图标轨悬停提示用 title 的替代实现（伪元素 tooltip），避免引入组件库。

## 布局与联动

- Bento 用 CSS grid 的 span 实现不等大模块（主模块 span 8 列跨 2 行是第6集示例值，按栅格总数等比缩放）。
- 筛选联动与悬停对比需要图表库支持数据补间与联动高亮（ECharts 的 connect 与 emphasis 可做）；无图表库时数字滚动可用简单计数动画顶替。
- 指标吸顶的连续收缩用 scroll 进度驱动内联样式（字号与间距插值），不要用滚动到点直接切 class 的二值做法。
- 详情抽屉与列表同屏：抽屉打开时列表容器收窄而非被遮罩盖住，当前行高亮保留，键盘上下事件只重渲染抽屉区域。

## 频控与降级

- 后台系统先保证信息密度与可读性：高密度卡片墙类风格须经用户确认场景后再用；动画一律提供减少动态偏好下的静态降级。

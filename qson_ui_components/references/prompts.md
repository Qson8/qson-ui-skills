# AI 描述词 - 交互组件（原创复刻版）

第10集多数描述词框未完整读出，第16集进度展开与刻度调节要点已核实。以下按正片机制原创撰写。

- 搜索展开：`点击圆形搜索按钮后，圆横向展开成输入框（形态过渡 300ms），光标自动定位，不要图标消失再换一框。`
- 图标变形：`汉堡图标变关闭图标用 SVG Path Morph：中线透明度和横向缩放归零，上下线各旋转45度；播放三角同理插值成暂停两竖，全程只改顶点不切图。`
- 状态链按钮：`提交后按钮内依次显示加载中、完成、结果文案，状态在按钮内走完一条链，不跳页不换按钮。`
- 指示条：`切换标签时底部指示条先拉伸到新位置再回缩落位，带弹性跟随感，不要瞬移。`
- 步进器：`点击加入按钮后原地展开成数量步进器，数量减到0自动收回成原按钮。`
- 顶栏收起：`页面滚动时顶栏按滚动进度连续收缩成图标（进度绑定 scroll offset），回滚到顶部重新展开，不要二值跳变。`
- 进度展开：`摘要面板平时只显示预计到达与联系人，点击展开路线区（高度过渡），三个节点进度依次填充，再点收起且按钮文案同步切换。`
- 刻度调节：`中央指针固定，横向拖动刻度尺调参，数值、预览图滤镜、外圈指示实时联动，松手吸附到最近刻度。`
- 分步选择：`兴趣选择一问一屏，每屏只答一个问题，选完自动进下一问，可回退改答案。`（回退为本库补充，正片未明示）
- 数据联动：`点击记录后数据面板数字滚动更新；切换单位或显隐时全盘同步变化，用单一数据源驱动。`

# AI 描述词 - 6 种弹窗可直接粘贴版

使用方式：把对应一段整段粘给 Codex / WorkBuddy / Cursor 等 Agent，再补上你的字段名和数据。括号里是可替换项。

## 通用底座（每次都带上）

```
做一个 Popup Sheet 弹窗，不要白框直接盖上来。分三段动画：
1) 背景先模糊+变暗 250ms；
2) 面板从底部升起 420ms，cubic-bezier(0.22,1,0.36,1)，大圆角 26px，柔和阴影，落定带轻微回弹；
3) 面板落定后，内部数字/进度/图形按 50ms 间隔依次动起来。
关闭：点背景或关闭按钮，面板下滑退出，背景恢复清晰。支持 prefers-reduced-motion 时降级为淡入。
```

## 1. 玻璃面板浮起 Frosted Glass Sheet

```
在通用底座上，面板做毛玻璃：半透明白 rgba(255,255,255,0.72) + backdrop-filter blur(20px) saturate(1.4)。
内容是 [12 个月份/打卡格子]，格子小圆角 10px，面板落定后格子按顺序逐个填充/打勾，stagger 50ms，不要同时出现。
```

## 2. 圆环进度弹出 Ring Progress Sheet

```
在通用底座上，面板深色底。中心一个圆环进度：圆环沿圆周从 -90° 画到 [目标百分比] 对应弧度，时长 850ms；
中心大数字与圆环同步从 0 计数到 [128]，不要直接跳终值。圆环下方放 [30/90/180/365] 刻度选项，圆环过半后淡入。
```

## 3. 刻度尺扫到今天 Tick Ruler Sheet

```
面板做票据造型：米白底、侧边齿孔/虚线分割、等宽字体显示日期和编号。
面板滑入落定后，一条横向刻度尺从 [起始日期] 连续扫到今天，时长 650ms，到今天位置高亮停住并轻脉冲一次；
完整编号默认隐藏，只显示一个“显示”按钮，点击后展开完整编号 [LF7K-XXXX]，展开用高度+淡入 250ms。
```

## 4. 照片抽屉贴合 Photo Drawer Sheet

```
点击照片后分两步：先照片放大铺满全屏宽度 350ms；然后底部抽屉上推 400ms，抽屉顶部与照片下沿完全贴合、无缝隙无外边距，抽屉只有顶部圆角 24px。
进度、文案和主按钮 [黑色胶囊按钮] 都在抽屉内部、随抽屉一起到位，不要浮在照片上。关闭先收抽屉，再把照片缩回原卡片。
```

## 5. 点击翻面凭证 Flip Voucher

```
卡片原地翻面，不要新开页面、不要左右滑。点击[查看凭证]后卡片绕 Y 轴翻转 600ms，perspective 1100px，
90° 时切换正反面（backface-visibility hidden），正面是凭证详情，背面是到场出示信息。再点一次翻回。翻转期间背景保持模糊。
```

## 6. 下拉展开面板 Pull Down Reveal

```
面板先从底部弹出到矮态（约 38% 高），只露摘要+顶部拖动把手（36x5px 小横条）+一个关键数字。
把手可拖拽，面板高度实时跟手；松手按阈值吸附到矮态或展开态（约 78% 高），吸附动画 300ms。
展开过程中完整信息 [总天数/日期/编号] 依次出现。保留关闭按钮和下滑关闭兜底。
```

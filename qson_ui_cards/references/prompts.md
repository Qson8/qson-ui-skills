# AI 描述词 - 卡片按钮交互（原创复刻版）

源视频本集未配描述词版式，以下按正片机制原创撰写。

- 定点弹出：`点击按钮后，卡片以按钮圆心为 transform-origin 从该点生长放大，到位略 overshoot 再收回；卡内文字做反向缩放补偿并延迟 60ms 淡入，不要从屏幕中心淡入。`
- 按钮变化：`提交按钮点击后先收成圆形，圆环旋转两圈表示处理中，再撑开成结果条显示结果，全程形态连续变化不跳页。`
- 甩动翻页：`轮播翻页由拖动位移和松手速度共同决定：拖过半慢松手翻一页，快速甩动翻两页；相邻卡按与中心距离连续缩放。`
- 列表转网格：`列表与网格切换时，每张卡的位置/尺寸/圆角按同一进度插值移动，卡内图片标题价签各有起止位，不要交叉淡化。`
- 筛选重排：`筛选时被筛掉的卡缩小淡出，留下的卡弹簧滑到新位置，新卡从空槽位长出，三类分别处理。`
- 券卡倾斜：`手指按住卡片时只有这张卡跟手倾斜约 8 度，卡面图案按 1.35 倍位移做视差，边缘高光随倾斜移动，松手回正。`
- 长按浮起：`长按 400ms 后卡片浮起（抬升加阴影），进入预览或操作状态，可取消；普通点击不触发。`
- 多选模式：`长按一张卡进入多选模式：全页卡片同时缩一档，出现勾选圈，底部操作条延迟约 100ms 入场，整页由一个 mode 状态驱动。`

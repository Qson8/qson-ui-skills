# qson-ui-principles - Apple 式审美原则

## 使用

- Invoke this skill when the user wants Apple style aesthetics, asks why a page looks cheap or template like, or mentions qson_ui_principles.

- This is a standalone skill in the qson-ui-skills family. The family index is the `qson_ui` skill.

- Read [the Apple style reference](references/apple-style.md) for the full rules from episodes 20 and 21 before reviewing or generating a page.

- 页面/界面评审（多角色评审、是否达标类问题）一律按 [设计成熟度评审标准](references/review-standard.md) 逐项打分：10 条 × 10 分、达标线 80、第 1/3/7 条为硬门槛。

## 静态审美规范（第20集）

- Build hierarchy with whitespace first: generous empty space and a grid like Bento set the reading order before any decoration.

- Let images be the protagonist and keep text restrained: photography sits at the visual center and words only explain.

- Keep dark and light modes visually consistent as one system, adjusting the whole visual together instead of only swapping the background.

- Use glass sparingly: a translucent panel floats over content while the content below and the control hierarchy stay readable.

## 交互落地准则（第21集）

- Write every linkage in one sentence that names the trigger, the responding objects and the way they change, so nothing is left to the implementer imagination.

- Reveal in batches with rhythm: titles first and works after, slices staggered, and feedback immediate, explicit and reversible.

- Preload the next item so fast switching never flashes empty, and when reduced motion is on, update content directly with no animation.

- Read [Apple Style](references/apple-style.md) for case evidence and the values episode 21 actually showed.

## 第20集 静态规范（三案例验证同一套规范）

案例：Morrow 灵感管理工具、Serein 视觉工作室、Afterimage 个人作品集。命题：同一套规范、三种表达。

1. 留白建立层次：Morrow 用 Bento 布局加大面积留白，观看顺序先整体、再看图片之间的关系；Serein 用大面积留白、横向摄影与克制文字让作品自己表达。
2. 图片优先：图片是主角，摄影卡片组织内容，横向摄影居视觉中心，文字只做克制说明。
3. 编辑式排版：Afterimage 用超大标题配不对称网格、摄影图文混排平衡画面；提示词写法是先交代排版关系，再写细节。
4. 深浅模式一致：切换深浅时整体视觉同步调整，而不是只换底色（与 qson_ui_dashboard 的主题四变量切换互为表里）。
5. 玻璃材质：以半透明控制中心式面板为例 — 面板浮于照片之上，仍能辨认底层内容与控件层级。
6. 反馈具体、联动写清：分类点击后非匹配卡片平滑退出、剩余卡自动重排；切换作品时主图与说明同步过渡；拖动光线滑杆时照片明暗实时变化；分类自动筛选作品；互动文字被鼠标经过时每个字母分别回应。
数值：本集未给出圆角、字号、间距、玻璃模糊值，不补编。

## 第21集 交互落地（双 Skill 分工，四案例）

工具分工：术语 Skill 给效果命名，UI 设计 Skill 给定规范（方法细节见 qson_ui_workflow）。
案例：个人主页、品牌资料库 Vellum、卡片设计站 LUMO、艺术展厅 TINCT，结语为工作流。

1. 空间层级：卡片错落排列先定主次；首屏整幅影像加大标题；共享元素过渡（卡片展开为详情页）连接两态。
2. 悬停反馈明确：悬停时卡片轻抬并加深阴影；点击当前卡翻面时其他卡退后，再点一次恢复。
3. 滚动揭示分批：标题先出现、作品随后进入，用分批揭示控制阅读顺序。
4. 状态联动：一处选中状态同步更新预览、名称与文件信息；点复制后立即显示完成状态，保留片刻后再恢复按钮；页面保留滚动提示。
5. 切换节奏一致：缩略图控制主卡内容，页面其他区域（工坊区）沿用同一套切换逻辑，不另起一套。
6. 切片与错峰：同一幅画分成五条切片错落排列，每片错峰入场，揭示有明确时长；预载下一张，快速切换不闪空；减少动态效果时直接更新内容、不做动画。

本集画面明示数值（仅限本集画面，不套用到第20集）：
- Vellum：纸色 #F1EDE4、正文 #242520；内距 24px、栏距 24px、圆角 16px；标题 24px、正文 16px；选中态 200ms、详情切换 300ms、复制确认保留 1.5 秒。
- TINCT：深绿 #101C1A、浅绿 #A2CBB8；五片间距 8px、正文 16px、作品名 24px、操作热区至少 44px；每片错峰 45ms、揭示 650ms。

## 两集共同避坑

- 不堆效果词、不做纯静态页；先定主导关系与画面主次，再把每次操作的触发条件、响应对象、变化方式写具体。
- 反馈即时、明确、可恢复；动效分批、有节奏；快速切换与减少动态时内容不闪空、不丢失。

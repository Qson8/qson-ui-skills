# 液态玻璃：实现与参数

管线与参数均按源包 LiquidGlass-Pack v2.0 原值（作者画心人，MIT）；着色器源码全文见同目录 `glass.frag` / `glass.vert`，可直接用于 Three.js / 原生 WebGL。源包另附零依赖 React 组件（LiquidGlassCanvas + useSpring + 四控件），本文件记其结构与关键数值，组件源码以源包为准（Qson 本机路径 `/Users/son/Downloads/LiquidGlass-Pack-v2`）。

## 渲染管线（WebGL 1）

1. 背景先画到离屏 canvas（图片 / 渐变 / 动态绘制 / DOM 截图均可），每帧上传为纹理。
2. 全屏四边形片元着色器：对每个像素，先由 SDF 场景函数求距离（多形状用 smin 按融合半径混合，分两层）；
3. 中心差分求 SDF 梯度 g（法线方向）；深度 `t = clamp(-d / band, 0, 1)`，衰减 `k = (1 - t^0.3)^2`；
4. 采样点偏移：折射 `uv - g * k * strength`；色散 `ca = -g * k * chroma`，R 通道采 `+ca`、G 采原点、B 采 `-ca`；
5. 每通道做 5 点十字平均（半径 = blur，约 1px）；
6. 边缘光：rim = 距边缘 7px 内的带，按光源角度与法线点积提亮（正向平方、反向立方 × 0.45）；
7. 白边：`mix(col, white, (1 - smoothstep(0, edgeWidth, |d|)) * edgeOpacity)`；
8. 磨砂混合：frost 越接近 1，颜色越被推向近白实心（开关静止态）；冷白着色 tint 另有一路 mix。
9. 真实文字、图标用绝对定位的 DOM 叠在画布上，与玻璃位置对齐，不进纹理。

每块玻璃的着色器入参（源包打包方式，可照搬）：`uR = (中心x, 中心y, 半宽, 半高)`、`uS = (圆角, 磨砂, 放大倍数, 折射倍数)`、`uT = (图层, 着色, -, -)`；全局 `uP = (strength, chroma, blur, band)`、`uE = (edgeWidth, edgeOpacity, 光源角度, 边缘光强度)`、`uM = (融合半径, 全局着色)`。单画布最多 8 块形状（uniform 数组上限），且听源包劝：**同屏 ≤ 5 块**。

## 玻璃参数表（源包原值）

| 参数 | 默认 | 范围 | 调大会怎样 |
|---|---|---|---|
| strength 折射强度 | 48 | 0~120 | 边缘弯得更狠，像更厚的透镜 |
| chroma 色散强度 | 12 | 0~30 | 彩边更明显；超过 20 开始显假 |
| band 折射带宽 | 60 | 10~140 | 弯折从边缘往里延伸更深 |
| blur 内部模糊 | 1.2 | 0~4 | 超过 3 变回毛玻璃，建议 ≤1.5 |
| edgeWidth 白边宽度 | 1.5 | 0~4 | 白边变粗；液态要细，1~2px |
| edgeOpacity 白边透明度 | 0.85 | 0~1 | 白边更亮 |
| frost 磨砂 | 0 | 0~1 | 1 = 白色实心（开关静止态） |
| mag 放大 | 1 | 1~2 | 放大镜倍数，滑块拖动态 1.6~1.9 |
| merge 融合半径 | 0 | 0~120 | 玻璃靠近时长出「桥」 |
| 阴影 | 无 | — | 不加，加了显脏 |

各控件的局部覆盖（源包组件内写定）：标签栏 strength 40 / band 36；开关 strength 26 / chroma 8 / band 24、滑块折射倍数 1.3；滑块 strength 30 / band 30；卡片 strength 60 / chroma 14 / band 70（卡片折射最强，作展示位）。

## 弹簧参数表（源包原值）

公式：`a = -k·(x - 目标) - 2ζ·√k·v`，逐帧积分。规律：k 大弹得快；ζ < 1 过冲、ζ = 1 临界不过冲。

| 用在哪 | k | ζ | 手感 |
|---|---|---|---|
| 按钮按压 / 指示器位置 | 300 | 0.5 | 冲过头再晃回来 |
| 开关滑块 横向缩放 | 250 | 0.6 | 与纵向不同步 → 果冻感 |
| 开关滑块 纵向缩放 | 250 | 0.7 | 同上 |
| 开关值 / 按下状态 | 1000 | 1.0 | 临界阻尼，干脆 |

## 坑与纪律（源包明示 + 本库整理）

- 全屏 WebGL 每帧都在算：同屏玻璃 ≤ 5 块；所有像素参数乘 `min(devicePixelRatio, 2)`，3 倍屏不封顶会卡（源包已内置）。
- 不依赖 `backdrop-filter`：它只能磨砂，做不出折射与色散；拿它冒充液态玻璃是本条的头号反模式。
- 玻璃下必须有内容：纯色空背景上折射不可见，先布置背景再放玻璃。
- 兼容性：WebGL 1，所有现代浏览器可跑（源包口径）。

## 跨平台提示（本库建议，非源包内容）

- Web / React：直接用源包组件或按上表自接着色器。
- Flutter：路线是 FragmentShader（FragmentProgram 加载同一份 GLSL 思路改写）+ 背景纹理截图喂入，或退而求其次用 BackdropFilter 做毛玻璃占位——后者按本条纪律只能算占位、不算液态玻璃。此路线本库未验证，用前先做小样验帧率。
- 原生 iOS 26 有系统级 Liquid Glass 材质，系统控件优先用原生，不必自绘着色器（常识口径，非源包内容）。

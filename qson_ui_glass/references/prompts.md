# 液态玻璃：AI 描述词

用法：把对应段整段发给执行 AI，替换里的内容。数值均为源包 LiquidGlass-Pack v2.0 原值（画心人，MIT）；整段提示词改编自源包《AI提示词.md》，按本库格式重组。

## 整段提示词（做一块真液态玻璃）

我要在项目里实现苹果 iOS 26 风格的「液态玻璃」，应用到上。

效果要求：
1. 折射：背景透过玻璃会弯折。中间几乎不变，越靠近边缘弯得越厉害，像凸透镜。
2. 色散：玻璃边缘有红蓝分开的彩边，颜色来自背景本身。
3. 外圈 1~2px 的细白边；内部只有约 1px 的轻微模糊（不能超过 3px，否则变成毛玻璃）；不加阴影。
4. 不要用 CSS backdrop-filter，它只能做磨砂，做不出折射和色散。用 WebGL 片元着色器。

实现方式：
- 一个全屏 WebGL 画布，背景内容先画到离屏 canvas（图片、视频、DOM 截图都行），每帧上传成纹理。
- 圆角矩形用 SDF：q = abs(p) - b + r; d = min(max(q.x, q.y), 0) + length(max(q, 0)) - r。
- 用中心差分求 SDF 梯度 g（指向边缘外侧）。
- t = clamp(-d / band, 0, 1)，k = (1 - t^0.3)^2；采样位置 uv - g * k * strength。
- R 通道采样 uv + ca，G 通道 uv，B 通道 uv - ca，其中 ca = -g * k * chroma。
- 每个通道做 5 点十字平均（半径约 1px）。
- 白边：mix(col, white, (1 - smoothstep(0, edgeWidth, abs(d))) * edgeOpacity)。
- 默认参数：strength 48、chroma 12、blur 1.2、band 60、edgeWidth 1.5、edgeOpacity 0.85。
- 所有像素参数乘 min(devicePixelRatio, 2)；同屏玻璃不超过 5 块。
- 真实的文字、图标用绝对定位的 DOM 叠在画布上，位置和玻璃对齐。

动作（弹簧）：
- 弹簧公式 a = -k(x - target) - 2ζ√k·v。
- 按钮按压、标签指示器：k 300、ζ 0.5（会过冲）。指示器拖动时按速度横向拉长、纵向压扁。
- 开关：静止时滑块是白色磨砂，按下变成透明玻璃珠并放大；横向缩放 ζ 0.6、纵向 ζ 0.7（k 250），两个方向不同步产生果冻感。
- 滑块：拖动时圆钮放大并变成放大镜（采样坐标向中心缩放 1.6~1.9 倍）。

## 单控件短提示词

- **玻璃标签栏**：「底部标签栏做成液态玻璃：底栏胶囊 屏宽减 24 × 72、圆角 36；指示器是叠在上层的第二块玻璃，跟随弹簧 k 300 ζ 0.5 移动并过冲，拖动时按速度横向拉长、纵向压扁；参数 strength 40、band 36，真折射加细白边，不要毛玻璃不要阴影。」
- **玻璃开关**：「开关滑块做液态玻璃果冻感：静止时滑块是白色磨砂实心，按下褪成透明玻璃珠并从 34 放大到 56；横向缩放弹簧 k 250 ζ 0.6、纵向 k 250 ζ 0.7，不同步出果冻感；开关值本身用 k 1000 ζ 1.0 临界阻尼；strength 26、chroma 8、band 24。」
- **玻璃滑块**：「滑块圆钮 40px，拖动时放大到 1.9 倍并变成放大镜：采样坐标向圆钮中心缩放 1.6~1.9 倍，压着轨道能看清刻度；strength 30、band 30，真折射加 1.5px 细白边。」
- **玻璃卡片**：「做一张可拖动的液态玻璃卡片 300×190、圆角 44：拖到哪里，哪里的背景就被凸透镜式弯折，边缘带红蓝色散和细白边；strength 60、chroma 14、band 70；卡片文字用 DOM 叠加，不要画进背景纹理。」

## 纠偏提示词（AI 做成毛玻璃时）

「这不是液态玻璃，只是毛玻璃：你只做了背景模糊。按液态玻璃的标准重做——SDF 圆角矩形求梯度，采样点沿梯度按 (1 - t^0.3)^2 衰减偏移做真折射，RGB 三通道分开偏移做色散，内部模糊降到 1.2px 以内，去掉阴影，补 1.5px 细白边和边缘光。」
